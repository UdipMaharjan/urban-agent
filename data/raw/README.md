# Raw project datasets

`urbanmart_feedback.xlsx` contains the 30 assignment-provided UrbanMart feedback
records. It uses the existing import contract with these columns:

```text
feedback_id, submitted_at, rating, feedback_text, source
```

The workbook preserves the supplied IDs, dates, ratings, feedback wording, and
source labels. Customer names and email columns are omitted because the source did
not provide those optional values.
