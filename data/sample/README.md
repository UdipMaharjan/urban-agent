# Excel sample

`feedback_template.xlsx` contains one worksheet with the seven supported column
names and three **synthetic** feedback examples. Replace those rows with your own
data before importing. They are not university dataset findings.

Only `feedback_id` and `feedback_text` are required. Keep IDs stored as **Text** in
Excel, especially values such as `001`. Use a stable `source` such as
`university_dataset` across repeat imports. See the root README for validation rules.
